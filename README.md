# First-Delta - GitHub Pages Repo

In preperation for some serious study of infosec (rather than just the odd bits I've been doing over the last few years...) I decided to start a blog/portfolio with somewhere to store my ramblings, document anything useful (including some study notes and command references) and share any experiences along the way.

As I didn't want to spend money on hosting or even think about playing with Wordpress again... GitHub pages was the obvious answer. I could have simple version control and use markdown which makes it easy to transfer notes from [Obsidian](https://obsidian.md).

After a bit of trial and error and finding a simplistic theme with decent features ([just-the-docs](https://github.com/just-the-docs/just-the-docs)), I managed to get my head around Ruby, gems and Jekyll. This also means I can test any changes locally before pushing to the main GitHub branch to make the changes live.

If you'd like any help with GitHub pages, feel free to [contact me](https://first-delta.github.io/contact/).
